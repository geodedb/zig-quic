## Triage Categories

Each row in the per-file table is assigned exactly one category:

- **impl-required** — production code does NOT yet exist for the rationale; the skip is an honest TODO that tracks an open requirement gap. The follow-up is implementation, not unskipping.
- **stale-rationale** — production code DOES exist for the rationale (verified by spot-check below). The skip is stale; follow-up is to write a real assertion, remove the skip, and route the test through existing code paths. Tracked under GAP-0004 / #88 and (where crypto-adjacent) GAP-0013 / #142.
- **cipher-availability** — guarded by `error.CipherNotAvailable` so the test compiles cleanly across BoringSSL/OpenSSL/no-AES build variants. Intentional and correct as-is.
- **harness-unsupported** — depends on an interop harness or external runner that is documented out-of-scope for the in-tree test suite (e.g. wrappers around `test-clients/` external implementations). The functional coverage is provided by `interop/` and `make interop-full`, not by the `tests/integration/interop/*.zig` placeholders.
- **out-of-scope** — explicitly de-scoped by repo policy or platform constraints (e.g. Linux-only regression tests on non-Linux hosts; certificate-fixture-missing branches that gracefully skip when keys are absent).
