Connection ID Analysis
======================

Client's View:
--------------
Initial Packet:
  My DCID: ed85df6cdef9d482c56b9e7f2ac16ca6 (16 bytes)
  My SCID: (empty) (0 bytes)

After receiving server's Initial:
  Switch DCID to: 8bd1f6093ae7540c (8 bytes)  <- Server's SCID

Expectation for coalesced packets:
  All packets in same datagram must have SAME DCID
  Initial packet has DCID=(empty), so Handshake must also have DCID=(empty)

Server's View:
--------------
Responding to client:
  My SCID: 8bd1f6093ae7540c (8 bytes)
  My DCID for Initial: (empty) (0 bytes) - CORRECT

  My DCID for Handshake: 8bd1f6093ae7540c (8 bytes) - WRONG!
    Should be: (empty) (0 bytes)


RFC 9000 Violation
==================

Section 12.2 - Coalescing Packets:
"Senders MUST NOT coalesce QUIC packets with different connection IDs
 into a single UDP datagram."

Server's coalesced datagram contains:
  1. Initial packet:    DCID=(empty)
  2. Handshake packet:  DCID=8bd1f6093ae7540c

These are DIFFERENT! Violation of RFC 9000.
